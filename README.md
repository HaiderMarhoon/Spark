SPARK
A Secure Blockchain-Integrated IoT System for Real-Time Energy and Water Consumption Monitoring

📌 Overview
This project integrates IoT, blockchain, cloud infrastructure, and mobile applications to create a secure, scalable, and real-time monitoring system for home utility usage—specifically energy and water. It is designed to help users track consumption, manage costs, and ensure data integrity through a tamper-proof architecture.

🧠 Abstract
This system leverages:

Raspberry Pi 3 Model B as the main IoT controller.

MCP3008 ADC for analog-to-digital data conversion.

ACS712 sensor to measure electric current.

Firebase (Google Cloud) for data storage and real-time syncing.

SHA-256 hashing to implement blockchain-based tamper detection.

Flutter mobile app for interactive user control and monitoring.

Users can:

View bills and usage history in real time.

Control connected devices remotely.

Receive immediate feedback through encrypted data sync.

✅ Features
🔐 Security: SHA-256 hashing ensures blockchain integrity.

☁️ Cloud-based: Firebase real-time database on Google Cloud.

📱 Mobile access: Built with Flutter for cross-platform compatibility.

🔄 Real-time updates: Instant device state and data sync.

📊 Usage monitoring: Tracks consumption trends with precise billing.

🧩 Modular design: Easily extendable for smart city integration.

🛠️ Tech Stack
Layer	Technology
